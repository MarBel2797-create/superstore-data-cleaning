# Очистка и подготовка данных Superstore (Data Cleaning)

Проект демонстрирует навыки предобработки "сырых" данных на примере датасета продаж супермаркета (Superstore). Включает обработку пропусков, удаление дубликатов, приведение типов данных и Feature Engineering.

## 🎯 Задачи проекта
1. Провести первичный разведочный анализ (EDA) и оценить качество данных.
2. Обработать пропущенные значения (NaN).
3. Найти и удалить дубликаты строк.
4. Привести типы данных к корректному формату (строки, даты).
5. Выполнить Feature Engineering: создать новые признаки на основе существующих данных.

## 🛠️ Инструменты
- **Python** (pandas, numpy)

## 📊 Этапы очистки данных

В ходе работы были выполнены следующие шаги:

### 1. Обработка пропусков и дубликатов
- Обнаружено и удалено **504 полных дубликата** строк.
- Удалены пустые строки, не содержащие информации о заказе.
- Пропуски в колонке `Postal Code` (почтовый индекс) заполнены заглушкой `'Unknown'`. Колонка приведена к строковому типу (`str`), чтобы избежать некорректного отображения (например, `98052.0`).

### 2. Работа с датами
- Колонки `Order Date` (Дата заказа) и `Ship Date` (Дата отгрузки) преобразованы из строк в формат `datetime` с помощью `pd.to_datetime()`.

### 3. Feature Engineering (Создание новых признаков)
- **`Delivery_Days` (Время доставки):** Рассчитано количество дней между заказом и отгрузкой.
  - *Результат:* Среднее время доставки составило **3.95 дня**. Минимальное время — 0 дней, максимальное — 7 дней. Аномалий (отрицательных значений) не выявлено.
- **`Order_Year` (Год заказа):** Извлечен год из даты заказа для дальнейшего анализа сезонности.
